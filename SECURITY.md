# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| > 0.1.0 | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

Please report security issues to `security@arenamind.ai`. We take all security vulnerabilities seriously and will respond promptly. Do not open a public issue for a security vulnerability.
